# Column 1: opening request (frozen grouping)

Frozen 2026-11-09, version v3. Do not edit: any change needs a new dated freeze.

Column 1 is NOT coded again. It is built from the final step-10 request types (`request_types_final_after_review`), one group per chat:

- **Asking to understand** = R1, R2, R7.
- **Asking what to do** = R3, R5, R6.
- **Just sharing information** = R4 only.

**Action wins** (researcher decision): a chat with both understand and act codes goes to 'Asking what to do', because the action question is what they really want.

**Implied requests** (decision L27, request codebook v6): request wording anywhere in the first message counts, with or without a question mark. A bare personal symptom or health change counts as an implied R1 and an own pasted test result as an implied R7, so these chats are 'Asking to understand'. 'Just sharing information' is only for messages that neither state nor imply a health request (for example a text pasted for another purpose).
