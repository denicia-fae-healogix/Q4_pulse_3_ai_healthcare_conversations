# Frozen path codebook, 2026-11-05, version v1

The locked codebook for the 3-column flow chart of the Q4 Pulse 3 health-advice study (opening request -> 2nd message -> when they shared background information). Drafted in step 11, piloted in step 12, and frozen after the researcher approved all 9 pilot edits (decisions L16-L24).

- `path_codebook.md`: the exact coding text the coders read (columns 2 and 3).
- `column1_grouping.md`: how column 1 is built from the step-10 request types.
- `path_codebook_definitions.csv`, `path_codebook_examples.csv`: the same codebook as tables.
- `path_decisions_log.csv`: every researcher decision (L1-L24).
- `SHA256SUMS.txt`: a fingerprint of each file. `python scripts/13_code-chat-paths/13a_freeze_path_codebook.py --verify` checks nothing has changed.

The files are read-only. Do not edit them; a change needs a new dated freeze.
